# ✈️ Airport Reservation System (Fullstack)

A modern flight reservation system built in a client-server architecture. The project focuses on backend logic, managing a relational database, and a responsive user interface.

## 🚀 Main Features
* Flight Search: Dynamic filtering of flights based on a PostgreSQL database.
* Reservation System: Booking form for multiple passengers with document validation (Regex).
* Newsletter: Module for saving users to a mailing list database (Backend Integration).
* Explore: Managing your own reservations (view for logged-in users).
* UI/UX: Dark mode user interface.

## 🛠️ Technologies
### Backend
* Java 17+ & Spring Boot 3
* Spring Data JPA (Hibernate)
* PostgreSQL (Relational database)
* REST API (JSON communication)

### Frontend
* React.js (Vite)
* Tailwind CSS (Styling)
* Lucide React (Icons)
* Framer Motion (Animations)

## 🔧 How to Run?
1. Backend: Set up your PostgreSQL database in application.properties and run mvn spring-boot:run.
2. Frontend: In the /skyreserve-frontend folder run npm install, then npm run dev.
